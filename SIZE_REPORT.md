# Size report

Generated by `./gradlew :app:sizeReport` from the release bundle with `bundletool get-size total`.
Download sizes are what Google Play sends to each device: the base module, its configuration
splits (one ABI, one density, one texture format) and the install-time `hd_assets` pack.
The gate requires every device to download between 100 and 190 MB
(1 MB = 1,000,000 bytes).
